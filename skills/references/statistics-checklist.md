# 统计学方法学检查清单

用于对心理学、临床心理学与医学论文的统计分析进行审稿核查。逐项记录发现并定位到稿件章节/图表。

## 1. 样本量与功效

- [ ] 是否报告了样本量如何确定（功效分析 / 可行性 / 惯例）？功效分析的参数（效应量、α、功效、预期脱落率）是否给出？
- [ ] 若为事后功效分析（post-hoc power），应指出其逻辑问题（事后功效与已得 p 值冗余，应改用置信区间宽度解读）。
- [ ] 小样本是否被如实承认并讨论其局限？

## 2. 效应量与置信区间

- [ ] 是否报告效应量（Cohen's d / Hedges' g / η² / 偏 η² / OR / RR / HR / r / R² 等）？
- [ ] 是否报告置信区间（通常 95% CI）？
- [ ] 是否区分"统计显著性"与"效应量大小 / 临床显著性"？

## 3. p 值与多重比较

- [ ] 是否报告精确 p 值（而非仅 p < 0.05）？
- [ ] 是否滥用显著性阈值（如把 p = 0.051 与 p = 0.049 作二元解读）？
- [ ] 多重比较是否校正（Bonferroni / FDR / 其他）？未校正是否说明并解释？
- [ ] 是否区分预设（confirmatory）与探索性（exploratory）分析？探索性结果是否被当作确证性结论（HARKing 风险）？
- [ ] 是否存在 p-hacking 迹象（大量未预设分析、选择性报告）？

## 4. 分布与模型假设

- [ ] 连续变量的正态性是否检验（或说明为何用参数/非参数检验）？
- [ ] 方差齐性、线性回归残差假设、独立性假设是否核查？
- [ ] 计数/二分类结局是否选用了恰当模型（如 logistic/Poisson/负二项）而非强行套用线性模型？

## 5. 缺失数据

- [ ] 是否报告缺失数据比例与缺失机制（MCAR/MAR/MNAR）判断？
- [ ] 缺失数据的处理方法是否恰当（完整案例分析 vs 多重插补 MI vs 混合模型）？
- [ ] 缺失是否可能引入偏倚，作者是否讨论？

## 6. 干预研究（RCT）特有

- [ ] 是否采用意向性分析（ITT）？脱落者的处理是否交代？
- [ ] 是否报告脱落率及各组脱落差异、脱落原因？
- [ ] 基线不平衡是否处理（调整/敏感性分析）？
- [ ] 是否控制多重结局的 I 类错误？
- [ ] 依从性（adherence）与干预保真度是否报告？

## 7. 观察性研究特有

- [ ] 混杂因素的选择依据（DAG / 文献 / 统计）？是否纳入足够且正确的混杂？
- [ ] 是否警惕过度调整（overadjustment，调整中介或共线性变量）？
- [ ] 是否用恰当的模型（多元回归 / 倾向评分匹配 PSM / 逆概率加权 IPW / 工具变量）？
- [ ] 因果推断措辞是否与设计匹配（观察性研究不应使用"导致/引起"等强因果措辞）？

## 8. 测量与量表

- [ ] 量表信度是否在本研究样本中重新报告（而非仅引用开发文献）？Cronbach's α 是否达可接受水平（通常 ≥ 0.70，且需说明单一 α 的局限）？
- [ ] 量表效度、临界值（cut-off）来源是否有依据？
- [ ] 是否报告测量误差/天花板或地板效应？

## 9. 重复测量 / 纵向数据

- [ ] 是否用恰当方法（混合效应模型 / GEE / 重复测量 ANOVA + 校正）而非忽略相关结构？
- [ ] 是否处理时间点间相关性与随机效应？

## 10. Meta 分析特有

- [ ] 效应量指标是否统一可合并？异质性（I²、τ²）是否报告并解读？
- [ ] 随机效应 vs 固定效应模型选择是否有理由？
- [ ] 发表偏倚是否评估（漏斗图不对称检验、Egger、trim-and-fill、p-curve）？
- [ ] 是否报告亚组/元回归与敏感性分析？是否评估证据确定性（GRADE）？

## 11. 常见审稿红旗（Red Flags）

- 仅报告 p 值、无效应量无置信区间。
- 小样本下做大量预测变量（模型过拟合，EPV < 10）。
- 结果部分只挑"显著"的变量写，与预设结局不一致。
- 结论中用因果语言描述相关/关联发现。
- 图表与正文数值不一致、自由度与样本量对不上。
- 事后把主要结局换成"更显著"的次要结局（outcome switching）。

> 核查时以稿件实际报告为准；对存疑的统计方法，可用 WebSearch 核验方法学规范，但不得替作者补做分析或臆造结果。
